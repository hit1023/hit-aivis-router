# 読み登録ガイド — ユーザー辞書 と 置き換えルール

AivisSpeech Router には読みを制御する方法が2つあります。  
**どちらを使うかの判断**が最も重要なので、まずそこから説明します。

---

## どちらを使うか

| 状況 | 推奨 |
|------|------|
| 単語そのものの読みが違う（固有名詞・人名など） | **ユーザー辞書** |
| 助詞・語尾を含めた読みを直したい | **ユーザー辞書**（品詞を普通名詞に） |
| 単語がどんな文脈でも同じ読みにしたい | **ユーザー辞書** |
| 特定の表記だけ別の読みに変えたい（略語・記号など） | **置き換えルール** |
| MeCab が複数形態素に分割してしまい辞書が効かない場合 | **置き換えルール**（最終手段） |

---

## ユーザー辞書の登録

### 基本的な登録手順

1. スプレッドシートの「単語辞書」シートを開く
2. 以下の列を入力する

| 列 | 内容 | 例 |
|----|------|----|
| 表層形 | テキスト中に現れる文字列 | `臍` / `新田|真剣佑` |
| 読み | カタカナで読みを入力 | `ヘソ` / `アラタ|マッケンユウ` |
| アクセント型 | 数字（0〜） | `0` / `1|3` |
| 品詞 | 下記参照 | `普通名詞` |
| 優先度 | 数字（高いほど優先） | `10` |

3. メニュー「辞書・置換」→「単語辞書をサーバに送信」で反映

### 複合語の登録（人名など）

**複数形態素にまたがる単語**（人名・地名など）は `|` で区切って登録します。

```
表層形:   新田|真剣佑
読み:     アラタ|マッケンユウ
アクセント型: 1|3
品詞:     人名
```

- `|` の数は表層形・読み・アクセント型で一致させる必要があります
- 区切り数が合わないと送信時にエラーになります

### 品詞の選び方

| 品詞 | 用途 | 備考 |
|------|------|------|
| **普通名詞** | 一般的な単語の読み修正 | MeCab の既存読みを上書きしやすい。**迷ったらこれ** |
| **固有名詞** | 地名・施設名など | 普通名詞で直らない場合に試す |
| **人名** | 人名（姓・名・フル） | 姓名を分けて `|` 登録する場合に使用 |
| **語尾** | 活用語尾の読み補正 | 単独では使いにくい。基本的に使わない |

> **ポイント：**  
> MeCab にすでに登録されている単語（`臍` = ほぞ など）は、**固有名詞より普通名詞のほうが上書きしやすい**ことがあります。  
> 読みが変わらない場合は固有名詞 → 普通名詞と変えて試してください。

### 優先度の目安

| 優先度 | 用途 |
|--------|------|
| `1〜5` | 通常の登録 |
| `10` | MeCab 標準辞書の読みを確実に上書きしたい場合 |

---

## 置き換えルールの登録

テキストを音声合成に渡す前に、指定した文字列を別の文字列に置き換えます。  
**MeCab の形態素解析より前に適用**されるため、辞書登録で対処できない場合の最終手段です。

### 登録手順

1. スプレッドシートの「置き換えルール」シートを開く
2. 以下の列を入力する

| 列 | 内容 | 例 |
|----|------|----|
| 対象文字列 | 置き換えたい文字列 | `臍石` |
| 置き換え後 | 置き換え後の文字列（読み仮名も可） | `セキセキ` |

3. メニュー「辞書・置換」→「置き換えルールをサーバに送信」で反映

### 有効な使い方

- **略語・記号の展開：** `㎝` → `センチメートル`
- **MeCab が分割してしまう複合語：** `臍石` → `セキセキ`（臍＋石と分割されてしまう場合）
- **完全に固定したい表記：** ブランド名など文脈に関わらず読みを統一したい場合

---

## ⚠️ 注意事項

### 1文字・短い文字列の置き換えは避ける

**悪い例：**
```
街 → マチ
```

このような登録をすると、テキスト中の **すべての「街」** が置き換えられます。

- `商店街` → `商店マチ`（不自然な分割）
- `街並み` → `マチ並み`（別の単語の一部まで置換）
- `街道` → `マチ道`（意味が変わる）

**正しいやり方：** 読みを修正したい単語は**ユーザー辞書**に登録する。  
`街` は普通名詞・優先度 10 で登録すると、文脈に応じた自然な読みに近くなります。

---

### 2. 助詞ごとに置き換えルールを作らない

**悪い例：**
```
街で → マチデ
街が → マチガ
街を → マチヲ
街は → マチワ
街に → マチニ
```

これは管理が煩雑になるだけでなく、  
`街での出来事` → `マチデの出来事`（想定外の変換）のように誤動作します。

**正しいやり方：** `街` をユーザー辞書に普通名詞で登録するだけで、  
助詞との接続は MeCab が自動的に処理します。

---

### 3. 置き換えルールの最長一致に注意

MeCab はテキスト中で**最も長く一致するルールを優先**します。  
ただし置き換えルールはMeCab より前に適用されるため、  
**部分一致で誤って置換されるリスク**があります。

登録前に「この文字列が別の単語の一部に含まれないか」を確認してください。

---

## よくある事例と対処法

| 症状 | 原因 | 対処法 |
|------|------|--------|
| 単語の読みが変わらない | MeCab の標準辞書が優先されている | 品詞を普通名詞に変更、優先度を 10 に上げる |
| 人名が一文字ずつ区切られて読まれる | 複合語として認識されていない | `|` 区切りで人名登録 |
| 登録した読みが別の単語にも影響する | 置き換えルールの対象が短すぎる | 置き換えルールを削除してユーザー辞書に移行 |
| 辞書送信時に「リスト長が一致しません」エラー | `|` の数が列によって異なる | 表層形・読み・アクセント型の `|` 数を揃える |
| 辞書を読み込むと品詞がすべて同じになる | 旧バージョンのバグ | 最新版に更新後、再読み込みする |

---

## 変更の反映タイミング

ユーザー辞書・置き換えルールは**送信直後から有効**になります。  
ただし、以下の場合は反映されないことがあります：

- スプレッドシートのデータがサーバに送信されていない（読み込んだだけで送信していない）
- 対象の単語が MeCab の標準辞書で強く優先されている（優先度を上げて再登録）
